# Frontend Completion Checklist

Before marking any frontend prompt done, verify:

- [ ] Page has loading state (skeleton cards or spinner)
- [ ] Page has empty state (message + action button)
- [ ] Page has error state (error message, not blank page)
- [ ] All amounts use Indian currency format ₹1,23,456
- [ ] All forms use React Hook Form + Zod
- [ ] Data fetching uses React Query
- [ ] Mutations use useMutation with onSuccess/onError toasts
- [ ] Modals use shadcn Dialog
- [ ] Drawers use shadcn Sheet
- [ ] Toasts use sonner
- [ ] Data tables use TanStack Table
- [ ] Layout is responsive (mobile + desktop)
- [ ] No `any` TypeScript types
- [ ] Navigation links work for all roles
